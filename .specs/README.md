# KanaPlay — Specs

**KanaPlay** is the Kanastra Frontend Hiring Challenge: a single-page application that
consumes the **Spotify Web API** to list artists, perform searches, and display artist
details. The UI follows a **Liquid Glass** aesthetic (glassmorphism — blurs,
transparencies, fluid elements) built on a **Yellow Ochre** brand palette
(`#C8922A` / `#E8B84B`) over a warm dark gradient background. The brand mark is a
playful **cheese-wedge logo** with Spotify-style signal waves embossed on it.

This folder versions the project specification alongside the code so the documentation
lives in Git next to the implementation it describes.
